Este projeto é uma lista de contatos, desenvolvido em HTML, PHP e JavaScript, utilizando o framework Materialize para estilização e o banco de dados SQLite para armazenamento dos dados. O projeto foi desenvolvido como atividade do curso Técnico em Desenvolvimento de Sistemas do SENAC.

O projeto pode ser acessado aqui 👉 https://www.lista-contatos.camilafbc.site/

## Visão Geral
Este sistema permite gerenciar contatos através de um formulário que coleta informações como Nome, E-mail e Telefone, além de um checkbox para indicar se o número de telefone é do WhatsApp. Após adicionar um contato, um card é criado exibindo os dados do contato. Ao posicionar o cursor sobre um card, um efeito hover revela as opções para deletar ou editar o contato, permitindo assim a execução de operações CRUD (Create, Read, Update, Delete) no banco de dados.

## Funcionalidades
- Adicionar Contato: Formulário para adicionar novos contatos com campos para Nome, E-mail, Telefone e um checkbox para WhatsApp.
- Exibição de Contatos: Contatos adicionados são exibidos em cards estilizados.
- Edição de Contatos: Permite editar os dados dos contatos existentes.
- Deleção de Contatos: Permite excluir contatos da lista.

## Tecnologias Utilizadas
* HTML
* CSS (Materialize Framework)
* JavaScript
* PHP
* SQLite
  
## Instalação
Para começar a utilizar ou testar o projeto, siga as etapas abaixo:

* Clone o repositório para o seu ambiente local:
* Certifique-se de ter um servidor local configurado, como o XAMPP, que inclui o Apache e o MySQL (ou SQLite).
* Inicie o Apache e o MySQL (ou SQLite) usando o painel de controle do XAMPP.
* Coloque os arquivos do projeto no diretório do servidor local. Por exemplo, no XAMPP, coloque os arquivos em C:/xampp/htdocs/nome-do-repositorio.
* Acesse o projeto através do navegador, indo para http://localhost/nome-do-repositorio.
