Este projeto é uma lista de compras, desenvolvido em HTML, PHP e JavaScript, como atividade do curso Técnico em Desenvolvimento de Sistemas do SENAC.

O projeto pode ser acessado aqui 👉 https://www.lista-compras.camilafbc.site/

## Visão Geral

Este sistema permite gerenciar uma lista de compras através de um formulário que coleta informações sobre os produtos, como Descrição, Marca e Quantidade. Após adicionar um produto, ele é exibido na lista com um checkbox para marcar seu estado como comprado. Os produtos comprados são movidos para o final da lista para uma melhor visualização. O sistema também inclui botões para deletar e editar produtos, completando as operações de CRUD (Create, Read, Update, Delete) no banco de dados.

## Funcionalidades
* Adicionar Produto: Formulário para adicionar novos produtos com campos para Descrição, Marca e Quantidade.
* Exibição de Produtos: Produtos adicionados são exibidos em uma lista.
* Marcar como Comprado: Checkbox para marcar produtos como comprados, movendo-os para o final da lista.
* Edição de Produtos: Permite editar os dados dos produtos existentes.
* Deleção de Produtos: Permite excluir produtos da lista.

## Instalação
Para começar a utilizar ou testar o projeto, siga as etapas abaixo:

* Clone o repositório para o seu ambiente local:
* Certifique-se de ter um servidor local configurado, como o XAMPP, que inclui o Apache e o MySQL (ou SQLite).
* Inicie o Apache e o MySQL (ou SQLite) usando o painel de controle do XAMPP.
* Coloque os arquivos do projeto no diretório do servidor local. Por exemplo, no XAMPP, coloque os arquivos em C:/xampp/htdocs/nome-do-repositorio.
* Acesse o projeto através do navegador, indo para http://localhost/nome-do-repositorio.
